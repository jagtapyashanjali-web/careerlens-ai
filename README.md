# CareerLens AI

## About the Project
CareerLens AI is a Job Market & Resume Skill-Gap Intelligence System. It analyzes 
job market data to identify the most in-demand skills for different career roles, 
then compares them against a candidate's resume to highlight matched and missing 
skills — helping job seekers understand exactly what to learn next.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn (TF-IDF, Cosine Similarity)
- Matplotlib & Seaborn
- Google Colab

## What I Did
- Built a skill-extraction system to detect technical skills from job descriptions and resumes
- Analyzed job market data across multiple roles (Data Analyst, Python Developer, 
  Machine Learning Engineer, Web Developer, Cloud Engineer, Data Scientist, Software Developer)
- Visualized skill demand, job location trends, and experience-level requirements
- Built a resume-to-job skill-gap analyzer that calculates a skill match percentage 
  and lists matched vs. missing skills for a target role

## Key Insights
- Skill demand varies significantly by role, with some skills (like Python and SQL) 
  in high demand across nearly every career path
- A resume's skill match percentage against a specific role can be calculated 
  automatically by comparing extracted resume skills to job requirement skills
- Visualizing skill gaps makes it easy to prioritize which skills to learn next

## How to Run
1. Clone this repository
2. Open the notebook in Google Colab or Jupyter Notebook
3. Run the cells step by step
4. Update the `resume_text` and `target_role` variables to test your own resume 
   against any job role in the dataset
